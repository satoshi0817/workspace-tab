# 詳細仕様

[使い方・インストールへ戻る](../README.md)

## Notion保存と振り分け

初期状態はローカル保存です。設定 → Notion保存でPATとDBを登録すると、お気に入りを起動時・約1時間ごと・手動操作で同期できます。PATはKeychainに保存します。新規DBの作成にも対応します。

お気に入りのCategoryに `Workspace ID` を設定すると、アプリタブのNotion Workspace IDと本番／開発環境で照合します。未設定の場合はCategory名とアプリタブ名を照合します。不正なIDや候補の重複がある場合は推測で別のログイン環境を開きません。

タブ情報は任意でNotionへバックアップし、手動で復元できます。CookieやPATは含みません。別のMacでは再ログインが必要です。

## 保存と制約

設定は `~/Library/Application Support/WorkspaceTabs/`、サイトデータはWebKitの永続プロファイル、NotionのPATはKeychainに保存します。設定は変更後と約5秒ごとに保存し、変更前のセッションを直近20件保持します。

- 未送信の入力、ページ内部の一時状態、Splitの幅は復元対象外です。
- 外部ブラウザやNotionデスクトップアプリのCookieは引き継ぎません。
- Notionの着色・画面操作・ワークスペース判定はNotion側の画面や保存形式に依存します。変更や権限によって動作しない場合があります。
- 新規ページのショートカットは作成メニューを開きます。ミーティングノートは直接作成するため、試す場合もページが残ります。
- Raycast用のローカル一覧は名前・アイコン・IDなどに限定し、PAT・Cookie・アカウントメモを含めません。連携用トークンを含む一覧ファイルやURLは共有しないでください。

## パフォーマンス・安定性

アイコンの縮小・メモリキャッシュ、変更時だけの保存／Raycast更新、WebKit通知の集約を実装しています。[調査・検証記録](PERFORMANCE_AUDIT.md)を参照してください。未送信入力を保持するため、表示済みタブの自動破棄は行いません。

通常のタブ切り替えはページを再読み込みせず保持します。再起動やWebKitプロセス終了後は、前回の画面を操作できないプレビューとして表示し、読み込み後に実際のページへ切り替えます。「表示を更新しました」は描画可能になったことを示し、Notion内部の同期完了を保証するものではありません。プレビューはログイン環境・ページ・URLごとにローカル保存し、最大32件・32 MiB、利用期限7日です。

お気に入りはLink Viewerと同様にカテゴリ別に表示します。CategoriesのOrder順、カテゴリ内はピン留め・リンクのOrder・名前順で、未分類は最後です。アプリの一覧では左右キー、Raycastでは⌘左右キーでカテゴリを切り替えられます。Raycastにも保存済みの画像アイコンを渡します。

Notionの新規AIチャット・新規ページ・ミーティングノートは、同じログイン環境の新しいブラウザタブで開きます。元のタブは保持します。Notion内の検索と「Notion：設定を開く」（初期値 ⌘⌥,）は現在のタブで実行します。キーは設定から変更できます。

## ワークスペース確認と作業の復元

- Workspace IDを設定したNotionタブには照合状態のアイコンを表示します。不一致時は案内バーから一致する環境で開けます。元のタブは閉じません。
- 新規ページ・AIチャット・ミーティングノートは、新しいタブで作成直前にWorkspace IDと本番／開発環境を確認します。判別できない場合は作成を中止します。Home URLには対象ワークスペースの通常ページを指定してください。ID未設定の環境は従来どおりで、照合はしません。内部メタデータを使うため、Notionの仕様変更で判定できなくなる可能性があります。
- 設定 → 作業：作業セットを保存・復元。現在のタブを閉じずに既存ページを再利用し、選択タブとSplit Viewを復元します。保存時のアプリタブ／ログイン環境がなくなった場合は中止します。RaycastのRun Commandにも保存したセットが並びます。
- 同じNotionページのURL別名は、お気に入り・外部リンク・作業セットで再利用します。異なるビュー、アンカー、本番／開発環境は区別します。明示的な新規タブや⌘クリックは新しいタブのままです。設定 → 作業から重複タブを確認できます。
- RaycastのOpen Notion Link、または `workspacetabs://open?url=<URLエンコードしたNotionのHTTPS URL>` からリンクを渡せます。URLのワークスペース名や既存タブで一意に決まらない場合は、開く環境を選択します。既定ブラウザは自動変更しません。ブラウザとして明示的に選んだ場合、Notion以外の外部リンクはSafariに渡します。
- 設定 → バックアップ：直近20件の構成履歴から復元。履歴復元は現在のタブを閉じるため、確認画面を表示します。ログインCookieや未送信の入力内容を履歴に保存する機能ではありません。
- 設定 → プレビュー：保存の全体／アプリタブ別切り替えと一括削除。オフにすると対象の画像も削除します。復元中の「前回の画面」にマウスを重ねると保存日時を確認できます。
- 設定 → 診断：直近200件のショートカット処理・タブ配置・読み込み時間をメモリに保持し、CSVに書き出せます。URL、ページ本文、入力文字は記録しません。タブ配置は描画完了、読み込みはNotion内部の同期完了を意味しません。

## 安定性と切り替え操作

- 起動時に壊れたセッションや消失した主ファイルを検出すると、最新の正常なバックアップから復旧します。壊れた元ファイルは Recovery に退避します。より新しいセッション形式は上書きせず停止します。
- ページ遷移・同じURLの再読み込み・終了後に古い非同期結果を適用しません。非表示になったタブの待機中のNotion操作もキャンセルします。すでに完了した作成を取り消す機能ではありません。
- お気に入り・検索・設定などを閉じた後は、元のWebViewへフォーカスを戻します。パネルから別のタブを開いた場合は、そのタブが対象です。
- プレビューの自動撮影は30秒以上の間隔を置き、入力やスクロールの直後2秒間と、非表示・最小化ウインドウでは実行しません。同じ画像はファイルを再書き込みしません。
- 通信復帰時の自動再試行は、一度も表示できていないページの失敗したGETに限ります。表示済みページ、フォーム送信、Notion作成コマンドは自動で繰り返しません。
- 診断には100ms以上のメインスレッド応答待ちと、8msを超えたセッション保存も記録します。スリープなど10秒以上の空白は応答待ちの記録から除外します。
- **⌃Tab** は最近使った順でアプリタブをまたいで選択します。Tabで次、Shift+Tabで逆順、修飾キーを離すかEnterで確定、Escでキャンセル。設定からキーを変更できます。メニューから開いた場合はEnterで確定します。
- 統合テストには切り替え／Split 200回、切り離し20回、タブ作成・終了40回を含め、未送信入力、ページ状態、エンジン解放、バックアップ復旧を検証しています。WebKit全体の長時間メモリ使用量を保証するものではありません。

ブラウザタブの標準アイコンはサイトのfaviconです。ページ内の指定を優先し、指定がなければ同じオリジンの /favicon.ico を使用します。取得できない場合は地球アイコンを表示します。アイコンはローカルに縮小保存し、アプリタブの画像とは分離します。個別に設定したブラウザタブの絵文字は優先されます。

ブラウザタブの「表示名・アイコンを編集…」から画像（PNG・JPEG・HEIC）を選択できます。画像はアプリ内に縮小コピーし、元ファイルを移動しても保持します。画像、個別の絵文字、faviconの順に優先し、「画像を解除」で戻せます。設定の書き出し・読み込みにも画像を含めます。

ブラウザタブはアプリタブごとにグループ分けできます。列の左端のピルで作成・名前変更・切り替え、タブの右クリックから所属グループを変更します。上下スクロールでも表示するグループを切り替えられ、左右スクロールはタブ列の移動に使います。グループを切り替えても表示ページは変わらず、タブをクリックすると切り替わります。グループ名・所属・表示中のグループは保存されます。削除時にはタブを閉じず先頭グループに戻します。

Notionのサイドバー着色は組織コンソールの左列にも適用します。既存の着色トグル・濃さ・ライト／ダーク設定を共有し、本文と選択中項目の背景は保持します。

ヘルプは検索とカテゴリ付きのカード一覧です。カードから操作手順を開き、「ショートカット」では現在の設定を確認できます。「はじめに」から導入ガイドをいつでも開けます。新規インストールでは、環境名・Home URL、表示、基本操作を3段階で案内します。途中でスキップでき、既存ユーザーには自動表示しません。ガイドの再表示では既存設定を書き換えません。

- [Safariのスタートページ設定](https://support.apple.com/guide/safari/customize-a-start-page-ibrw01514823/mac): プレビューしながら表示を選び、後から調整できる流れ。
