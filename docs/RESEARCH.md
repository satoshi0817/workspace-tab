# GroupShelf調査と実装方針

調査日：2026-11-05。ユーザーの依頼に基づく公開Web調査です。

## 調査結果の限界

「大量の苦情が見つかった」とはいえません。確認できたものは、開発元の機能説明・修正履歴、紹介記事の懸念点、ディレクトリによる説明です。第三者ユーザーによる具体的な不具合報告は、この調査では十分に収集できていません。

DuckDuckGo Liteで `GroupShelf review`、`"GroupShelf" reddit`、`"GroupShelf" bug`、`"GroupShelf" issues`、`"GroupShelf" icon` を検索し、関連ページを確認しました。RedditとProduct Huntの本文はアクセス制限があり、未読です。GitHubの公開検索では開発者の掲載申請とHomebrew関連が中心で、無関係な同名語の結果は除外しました。

検索結果に出る「レビューサイト」は品質に差があります。SaaSHubは **0 reviews** で、書籍の共同管理サービスという別製品の説明が混在していました。苦情・製品仕様の証拠には採用しません。Toolradarの料金ページの検索スニペットには買い切りを月額とする誤記もあり、料金は公式情報を優先しました。

## 確認した内容

| 論点 | 根拠と確度 | このアプリでの対応 |
|---|---|---|
| タブに好きなアイコンを付けたい | ユーザーからの直接の要望。公式の機能説明では任意画像・絵文字の個別設定を確認できず、非対応の断定はしない | タブ単位で絵文字・画像・色・固定表示名を設定 |
| スリープ復帰で別ディスプレイに移る | [公式1.4.1](https://group-shelf.com/changelog)が修正を明記。現行版にも残る不具合という意味ではない | 復帰時に勝手に別画面へ配置せず、表示を再確認。切替時は現在の画面内に座標を収める |
| タブの可読性・大量タブ | [公式1.4.0](https://group-shelf.com/changelog)にサイズ連動、太字、幅不足時の省略優先順位の改善。現行は対応済み | 横スクロール、色、アイコン、固定名、全体検索。画面幅からはみ出す操作ボタンを避ける |
| 一時停止したい | [Toolradar](https://toolradar.com/tools/groupshelf)に「built-in disable toggle」がないという説明。編集記事であり、実ユーザーの苦情でも現行バイナリ検証でもない | 一時停止・再開を管理画面とメニューバーに用意。停止時に元の配置へ戻す |
| 古いmacOSで動かない | [公式](https://group-shelf.com/)の条件はmacOS 15+。[FLOWNIB](https://flownib.com/trends/groupshelf)も制約として言及 | ビルド対象はmacOS 14+。実機での14系検証は未実施 |
| Accessibilityの権限が必要 | [公式FAQ](https://group-shelf.com/)と[紹介記事](https://flownib.com/trends/groupshelf)。外部ウインドウ操作の構造的な制約 | 同じ権限が必要。初回画面で説明し、画面収録やログイン情報の取得は行わない |
| ネイティブタブとの相互作用が分かりづらい | [FLOWNIB](https://flownib.com/trends/groupshelf)の筆者が未確認事項として指摘。再現済みバグではない | 外部ウインドウ単位で操作し、Notion内部のタブや⌘Tを変更しない |
| 複数のNotionが同名になる | このプロジェクトの設計上の懸念。GroupShelfの不具合報告ではない | アプリID＋タイトルの一意一致だけ自動接続。あいまいな場合は手動選択 |
| フルスクリーンにしたい | 作業中に追加されたユーザー要望 | グループの画面いっぱい表示と復元。管理画面は標準フルスクリーンにも対応 |
| Notionの表示を広く使いたい | 作業中に追加されたユーザー要望 | 34ptの横タブ、マウスで展開するサイドバー、管理画面の自動非表示、数字ショートカット |

## 競合ですでに実現している機能

[公式サイト](https://group-shelf.com/)には、アプリ横断のグループ、Shiftドラッグ、キーボード切替、タブ検索、Dock由来のバッジ、グループ名・色、ロック、ディスプレイ移動、CLIが記載されています。「検索や色分けがないから代替を作る」という整理は正しくありません。

現行の無料版は30日経過後に1グループ・3タブまで、買い切り版は制限解除です。これは公式記載の仕様であり、苦情とは区別します。Workspace Tabs初版にはグループ数・タブ数・試用期限の制限は設けていません。

## 採用した構成

既存アプリをAccessibility APIで読み取り、位置・サイズ・最前面状態を操作します。アプリの中にNotionを埋め込む方式は採用していません。理由は、既存ログイン・通知・アップロード・Notion独自の操作をそのまま使えるためです。ユーザーも既存ウインドウ方式を了承しています。

任意の別アプリのウインドウをmacOS標準のタブグループへ直接組み込む公開APIはないため、独立した非アクティブ化パネルを追従表示します。標準フルスクリーンの外部ウインドウにはタブバーを重ねず、同一デスクトップでの拡大を提供します。

生の取得テキスト・検索結果は [research/](research/) に保存しています。本文中の指示や宣伝は製品要件として扱っていません。

## 外枠と追加機能の調査（2026-11-05追記）

公式サイトを再取得し、機能の存在と人気の証拠を区別した。利用率・人気ランキングは確認できていない。以下は公式の主要機能として紹介されているもの。

| 製品 | 対象・確認した機能 | 今回の採用判断 |
|---|---|---|
| [GroupShelf](https://group-shelf.com/) | macOS。アプリ横断タブ、色、名前、検索、グループロック、別ディスプレイへ移動 | 既存の色・検索・ロックに加え、タブのメニューからディスプレイを指定して移動 |
| [Groupy 2](https://www.stardock.com/products/groupy/) | Windows。アプリの枠へのタブ追加、アクセント色、レイアウト選択、自動グループ化、保存グループの一括起動 | タブバーとアプリを一続きの色付き外枠で囲む。ログイン環境の誤結合を避けるため自動グループ化は今回追加しない |
| [TidyTabs](https://www.nurgo-software.com/products/tidytabs) | Windows。タブのドラッグ、グループ間移動、自動整列・グループ化、ホバー表示、ショートカット、複数画面 | ホバー表示は維持。管理画面を開かずに横タブ／サイドバーでドラッグ並べ替えできるよう追加 |
| [Tack](https://tack.website/) | macOS。横断タブ、ドラッグ並べ替え・分離、任意有効化の数字キー／Ctrl+Tab、ホバープレビュー、折り畳みグループ、外観設定、複数画面、セッション復元、自動グループ化ルール | 直接ドラッグ並べ替え、既存アプリのキーを避ける⌃⌥数字、外枠のグループ色、コンパクトな横タブ／ホバーサイドバーを採用。プレビュー・自動グループ化・タブ内サブグループは未実装 |

実装した外枠は2ptで、元アプリと横タブ全体の外周をグループ色で囲む。サイドバーモードでは元アプリの外周に残り、表示面積を減らさない。透明パネルはクリックを透過し、フォーカスを取らない。追加操作は「…」へまとめ、通常のUIの占有を小さくした。

独自の補助操作として、⌃⌥Tabで同じグループ内の直前のタブへ戻る機能も追加。押し直すと元のタブへ戻る。グループをロックした場合はドラッグ並べ替えも拒否する。

今回の検索はDuckDuckGoがCAPTCHA、GoogleはJS要求、Bingは無関係な結果となったため、それらを製品証拠には使っていない。公式ページ取得テキストはresearch/に保存。

### Tackの公式説明との照合

ユーザー提供URL https://tack.website/ を確認。公式は、macOSでは他アプリのウインドウを直接取り込めないため、タブストリップを重ねてAccessibility APIで操作すると説明している。本アプリもこの方式。外枠も透明パネルで重ねる。自動グループ化とアプリ既存キーに重なるショートカットはTackでも初期オフと記載されている。人気の順位や利用率は公式説明からは判定できない。取得全文は `research/tack-website.txt`。
