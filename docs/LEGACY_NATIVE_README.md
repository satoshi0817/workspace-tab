旧外部ウインドウ版の履歴です。現行仕様はREADME.mdを参照してください。

> 現在の保存仕様：タブ名・アイコン・色・順序・選択・配置を保存し、5秒ごとにウインドウ情報を確認します。閉じた／見つからないウインドウのタブ設定も保持します。起動時と監視時に一意に照合できるウインドウを復元し、同名などで判別できなければ「保存済み」として残します。管理画面の「ウインドウを選ぶ」で対応先を指定できます（ロック中は先に解除）。変更前の設定はBackupsに直近20件保持します。本文・認証情報を保存する機能ではなく、Notion自体のページやログイン状態を再生成するものではありません。

> 表示設定の更新：タブヘッダーは42pt。通常ウインドウが開いていれば、他アプリや管理画面を操作している間もヘッダーを表示します。最小化・アプリを隠す・標準フルスクリーン・一時停止・未接続時は対象のヘッダーを表示しません。設定 → 表示 → テーマで「システム／ライト／ダーク」を選択でき、次回起動にも引き継ぎます。テーマはWorkspace Tabs自身に適用します。

> 現在の表示：上部の横タブ／左側の縦タブ＋共通の外枠を選べます。設定 → 表示 → タブの位置、またはタブバーの … → タブの位置で切り替えます。タブバー単体のドラッグ移動はできません。管理画面のグループ一覧は引き続きホバー表示できます。アプリのタイトルバーでの移動・端でのリサイズを、同じグループの背面ウインドウにも反映します。macOS上で別アプリを本当に子ウインドウとして埋め込む方式ではありません。

# Workspace Tabs

macOS上で、既存のNotionなどのウインドウをアイコン付きタブで切り替えるアプリです。Swift / AppKit / SwiftUIで実装し、外部ライブラリは使用していません。

## 起動

ビルド済みアプリ：`/Applications/Workspace Tabs.app`

1. 初回起動時に、システム設定 → プライバシーとセキュリティ → アクセシビリティで **Workspace Tabs** を許可します。許可後に反映されない場合はアプリを終了して開き直してください。
2. Notionでワークスペースごとに通常のウインドウを開きます。
3. 「グループを作成」から、まとめるウインドウを選択します。
4. タブを右クリックするか管理画面の編集ボタンを押すと、表示名・絵文字・画像・色・固定を変更できます。

既存ウインドウのログイン状態を利用します。別アカウントのセッションを分離したり、Notionにログインしたりする機能はありません。

## 操作

| 操作 | 方法 |
|---|---|
| タブ切り替え | タブをクリック、または Control + Option + ← / → |
| 番号でタブを切り替え | Control + Option + 1〜9 |
| 全グループのタブを検索 | Control + Option + Space |
| タブの名前・アイコンを変更 | 管理画面の編集ボタン、または右クリック |
| タブ並べ替え | 管理画面の行をドラッグ、または右クリック → 左 / 右に移動 |
| グループを移動 | 元アプリのタイトルバーをドラッグ |
| ドラッグで追加 | 未登録ウインドウのタイトルバーをグループへ重ね、1秒待ち「離すと追加」で離す |
| グループを画面いっぱいに表示 | タブバー右端の拡大ボタン。再度押すと元のサイズ・位置に戻る |
| 管理画面の標準フルスクリーン | Control + Command + F、または「ウインドウ」メニュー |
| 一時停止・配置復元 | 管理画面左下、またはメニューバーから一時停止 |
| タブを閉じる | タブを右クリック → タブを閉じる… → 確認。元ウインドウは閉じません |
| バックアップ | 設定 → 書き出す。画像アイコンも含めてJSONに保存 |
| バックアップ読込 | 設定 → 読み込む。既存設定に別グループとして追加 |
| 管理画面のグループ一覧 | 既定では左端へマウスを重ねたときだけ表示。設定で常時表示に変更可能 |

数字ショートカットは他のアプリからも利用でき、最後に選んだグループのタブ順に対応します。矢印ショートカットは管理対象のウインドウが最前面の間だけ登録し、別アプリの矢印操作を取りません。ショートカットが競合した場合は通知します。

タブを選ぶと管理画面を閉じ、元のアプリを表示します。上部固定タブは高さ42ptです。ドラッグ追加は設定で無効化でき、待ち時間を0.5〜3秒から選べます。領域外へ移動するとキャンセルします。ロック中・最小化・アプリ非表示・標準全画面のグループや、複数グループが重なって対象を特定できない場所には追加しません。

## ウインドウとデータの扱い

- タブを選択すると、対象ウインドウをグループの位置・サイズに合わせ、最前面に出します。非選択ウインドウを閉じたり最小化したりしません。
- 外す・グループ解除・一時停止・通常終了で、接続時の配置へ戻します。取り外したディスプレイ上にあった場合は、現在の画面内に収めます。
- 起動時はアプリIDとタイトルが一意に一致する開いているウインドウだけタブを復元します。一致しないタブも設定を保持します。運用中は5秒ごとに照合し、閉じたウインドウのタブは保存済みとして残します。一時的な応答待ちでは削除しません。
- ウインドウをクリックして直接切り替えた場合も、選択タブを追従させます。
- タブ名はウインドウタイトルとは別に保持するため、Notionのページを変えても表示名は変わりません。
- タブバーは他アプリの操作中も表示します。選択タブの切断時は接続済みタブを優先します。最小化・アプリ非表示・標準全画面・一時停止・接続済みタブがない場合は非表示です。
- 設定は `~/Library/Application Support/WorkspaceTabs/workspaces.json`、画像は同フォルダの `Icons/` に保存します。本文・キー入力・Cookie・認証情報を取得せず、ネットワーク通信や画面収録も使いません。
- 読み込めない設定ファイルは上書きしません。読み込みエラーを画面に表示します。

## 対応範囲

この版はmacOS 14以降向けです。提供バイナリはこのMac用のApple Siliconビルドで、ローカルのApple Development証明書で署名しています。Developer ID配布・公証は行っていません。

グループの拡大は、タブバーを残すために同じデスクトップの使用可能領域へ広げる機能です。macOS標準の別Spaceを作るフルスクリーンとは異なります。標準フルスクリーン中の外部ウインドウは管理対象から除外し、解除後に利用します。

アプリによって位置・サイズ変更やAccessibility APIへの対応が異なります。サイズの最小値が大きいアプリ、別Space上のウインドウ、Stage Manager、画面切替・スリープ復帰の全組み合わせは検証を継続する必要があります。選択リストと、一定時間重ねて離すドラッグ操作で追加できます。アプリがクラッシュ・強制終了した場合、通常終了時の配置復元は実行できません。

## 開発

AppleのCommand Line Toolsがあればビルドできます。通常のプロジェクトディレクトリでSwiftPMのビルドDBがI/Oエラーになったため、スクリプトでは `/tmp/workspace-tabs-build` を使用しています。

```sh
rtk proxy bash scripts/build.sh --install
rtk proxy swift run --scratch-path /tmp/workspace-tabs-build WorkspaceCoreChecks
rtk proxy '/Applications/Workspace Tabs.app/Contents/MacOS/WorkspaceTabs' --diagnose
```

この環境のCommand Line ToolsにはXCTest / Swift Testingが含まれないため、検証は依存なしの実行可能ターゲットにしています。失敗時は非ゼロで終了します。

```sh
rtk proxy bash scripts/build-fixture.sh
```

このコマンドは実データを持たない4つの検証用ウインドウを作るアプリを `build/WorkspaceTabsFixture.app` に生成します。

検証アプリを起動した状態で、実ウインドウ操作の検証も実行できます。指定したbundle IDの検証用ウインドウだけを操作し、終了時に配置を復元します。

```sh
rtk proxy swift run --scratch-path /tmp/workspace-tabs-build WorkspaceTabs --verify-fixtures
```

## 外枠とクイック操作

- 選択中タブの色の4ptの外枠でアプリとタブを囲みます（非アクティブ時は3pt）。本文の表示領域は縮めません。
- 横タブでタブをドラッグし、別のタブへドロップするとその手前へ移動します。グループのロック中は変更できません。
- **Control + Option + Tab**：直前のタブへ戻る（管理対象ウインドウが前面の間）。もう一度押すと往復します。
- タブバーの **…**：ディスプレイへ移動、グループのロック、管理画面。
- 外枠は実アプリに重ねる透明パネルです。独立したアプリをOS上で一つのウインドウに埋め込む方式ではありません。

- [切断・ヘッダー消失の調査とドラッグ追加の検証範囲](docs/STABILITY_AUDIT.md)

Workspace Tabs内でタブを閉じるときは確認アラートを表示します。キャンセルが既定です。元アプリの閉じるボタン・⌘W・終了操作を事前に止めることはできないため、その場合は接続のみを解除し、タブ設定は保存済みとして保持します。固定・ロックは手動削除を防ぎますが、閉じたウインドウのタブ設定も保持します。

## タブの色と文字色

タブの編集画面で背景色をプリセット、カラーピッカー、#RGB／#RRGGBBから選べます。文字色は「自動／白／黒」。選択中タブの背景色と文字色がヘッダー全体へ反映され、選択タブには太い枠と下線を表示します。既存設定は自動文字色として読み込みます。

## Mission Control

外部アプリのウインドウは独立したOSウインドウのため、Mission Controlでは別々に表示されます。AppKitのcollectionBehaviorは自アプリのNSWindow向けで、AX経由の外部ウインドウを一つの項目にまとめる公開APIはありません。非選択ウインドウの最小化による回避は通常操作へ影響するため実装していません。本当に一つにまとめるには、アプリ内WebView等で表示を所有する構成への変更が必要です。

参照：[Apple managed](https://developer.apple.com/documentation/appkit/nswindow/collectionbehavior-swift.struct/managed)、[transient](https://developer.apple.com/documentation/appkit/nswindow/collectionbehavior-swift.struct/transient)、[stationary](https://developer.apple.com/documentation/appkit/nswindow/collectionbehavior-swift.struct/stationary)。

## 選択タブの強調と縦タブ

- 選択中はチェックマーク、太枠、ライン、太字。非選択タブは控えめに表示します。「表示中」の文字ラベルは表示しません。
- 左側の縦タブは幅220ptを確保し、アプリ本文を右へ配置します。切替時は共通の外枠を維持する計算で内容領域を変更します（アプリ固有の最小サイズ制約は適用されます）。
- タブが多い場合はスクロール。選択が変わるとそのタブが見える位置へ移動します。並べ替え・右クリック・数字ショートカットは両表示で共通です。
- 表示方向は全グループ共通で、次回起動にも引き継ぎます。縦タブは通常・アイコンのみ・左端で展開の3種類から選べます。

アプリの角丸とタブ領域の継ぎ目は、選択中タブの色で塗りつぶします。透明・クリック透過の外枠パネルに標準的な12pt角丸の補完形状を描く方式で、元アプリの角丸そのものを変更しません。独自の角形状を持つアプリでは完全には一致しない場合があります。

## サイドバーの収納と終了

設定 → 表示 → サイドバーの表示、またはタブバーの … → サイドバーの表示から変更します。

- 通常：220ptで名前とアイコンを表示。
- アイコンのみ：56pt。タブ名はツールチップから確認。
- 左端で展開：ワークスペース左端に8ptのハンドルを残し、マウスを重ねると220ptへ展開。離れて0.25秒後に収納。展開部分は本文の上に重なり、本文の幅は変えません。

タブバーの … → Workspace Tabsを終了… から終了できます。終了確認でキャンセルすると継続し、終了を選ぶと元ウインドウを閉じずに元配置へ戻します。メニューバーの終了と⌘Qにも同じ確認が出ます。

Mission Controlでタブパネルが残るstationary指定を除去し、transient（Mission Controlで非表示）へ変更しました。元アプリのウインドウがMission Controlで別々に表示される点は変わりません。

## 外周の表示（最新）

共通外枠と、元アプリの角丸の隙間を塗り足すパネルは廃止しました。サイドバー・ヘッダー自体を四隅12ptの連続角丸に揃え、元アプリの形状をそのまま表示します。上記の外枠・角丸補完の説明は旧仕様です。アイコンのみのボタンは高さ42pt、アイコンを上下左右中央に配置します。

タブ領域と元アプリの間には4ptの隙間を設けています。横・縦・アイコン・収納ハンドルで共通です。領域幅は通常220pt／アイコン56pt／収納8ptで、その外側に4ptを確保します。

サイドバーのタブ一覧下の空白部分は、ドラッグでグループ全体を移動できます。通常・アイコンのみ・ホバー展開中に対応。タブ上は並べ替えのままです。移動中も元ウインドウのサイズを保ち、ドラッグ終了時は画面内へ収めます。
