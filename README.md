# Workspace Tabs

仕事用・個人用などのログイン環境を分けて、Webサイトをひとつのウインドウで使えるmacOSアプリです。

## できること

- **環境を分ける** — アプリタブごとにログイン環境を選び、名前・色・アイコンで見分けられます。
- **タブを整理する** — グループ分け、ドラッグでの並べ替え、ピン留めに対応します。
- **アイコンで見分ける** — グループ・各タブ・お気に入りに、画像や検索できる885個のプリセットを設定できます。
- **2つのページを並べる** — 異なるアプリタブのページもSplit Viewで表示できます。
- **すぐに移動する** — 全タブ検索、お気に入り、キーボード操作、Raycast連携が使えます。
- **作業を再開する** — 開いていたタブや選択状態を保存し、次回起動時に復元します。

新しい環境の初期色はグレーです。左サイドバー・上部タブ、アイコンのみの表示、左端にマウスを寄せると展開する表示を選べます。ライト／ダーク／システムテーマにも対応します。

## インストール

**macOS 14以降・Apple Silicon搭載Mac**に対応した試用版を配布しています。v0.2.0のDMGはビルド4へ更新し、グレーの初期色・最新のアイコン設定・リンク受け取り・読み込み失敗時の再試行を含みます。ソースからビルドする場合はmainブランチを使用してください。

1. [ダウンロードページ](https://github.com/satoshi0817/workspace-tab/releases/tag/v0.2.0)の **Assets** から `Workspace-Tabs-0.2.0-arm64.dmg` をダウンロードします。
2. DMGをダブルクリックして開きます。
3. **Workspace Tabs.app** を隣の **Applications** フォルダへドラッグします。
4. アプリケーションフォルダから **Workspace Tabs** を開きます。

インストール・利用にターミナル、Xcode、Python、Homebrewなどの追加ツールは不要です。更新時は、起動中のWorkspace Tabsを終了してから入れ替えてください。リポジトリが非公開の場合、ダウンロードにはアクセス権のあるGitHubアカウントでのサインインが必要です。

現在の試用版はAppleの公証を受けていません。初回起動をmacOSが保留する場合は、配布元を確認したうえで、システム設定 → プライバシーとセキュリティに表示される「このまま開く」から許可してください。

Intel Macで使う場合や自分でビルドしたい場合は、下の[ソースからビルド](#ソースからビルド)を参照してください。

## 使い始める

1. 初回起動時のガイドで、環境の名前・ホームURL・表示を設定します。
2. 内蔵ブラウザでサイトにログインします。
3. サイドバーの **＋** から、仕事用・個人用などのアプリタブを追加します。ログインを共有したい場合は同じログイン環境を選びます。
4. **⌘T** で新しいタブの選択画面を開きます。**→** の「URL・検索」では、URLを入力すればそのサイトを開き、キーワードならGoogle検索します。
5. タブを右クリックして、名前・アイコン・ピン留め・グループなどを調整します。

操作に迷ったらサイドバーの **？** を開いてください。検索できるヘルプと、導入ガイドの再表示があります。

## アイコンを変える

- グループはタブ列左端の名前をクリック → **グループを編集…**
- アプリタブ・ブラウザタブは右クリックから編集
- お気に入りは編集画面から設定

**プリセット…** では検索・カテゴリから選び、**画像…** ではPNG・JPEG・HEICを選びます。選んだアイコンはこのMacに保存され、元の画像ファイルを移動しても残ります。プリセットは文字と同じ色で表示します。

## よく使う操作

| キー | 操作 |
| --- | --- |
| ⌘T / ⌘W / ⌘⇧T | タブを追加／閉じる／復元 |
| ⌃⌥1〜9 | アプリタブを番号で切り替え |
| ⌘⌥← / → | 前／次のアプリタブ |
| ⌃⌥Space | すべてのタブを検索 |
| ⌃Tab | 最近使ったタブに切り替え |
| ⌘⇧L | お気に入りを開く |
| ⌘⇧P | コマンドを検索 |
| ⌘L | URLバーを表示 |
| ⌘⇧N | Notionの作成メニューを表示 |
| ⌘⇧C | 現在のURLをコピー |
| ⌘, | 設定を開く |

**⌘またはアプリタブ切り替えの修飾キーを約0.5秒長押し**すると、対応するキーがアプリタブに表示されます。キーを離すと消えます。切り替えの割り当て自体は変わりません。

作成メニューでは、↑↓とEnter、数字1〜5、クリックで選べます。Escまたは外側のクリックで閉じます。

キーはすべて初期値です。設定 → ショートカットから、同時押しや連続入力を記録し、操作ごとに変更・リセットできます。

## Raycastから使う

Raycast、Node.js 22.22.2以降、npmが必要です。リポジトリのルートから実行してください。

```sh
cd raycast
npm ci
npm run dev
```

開発用拡張として登録されます。Workspace Tabs本体も起動してください。

- **Search Favorites**：お気に入りを検索して開く
- **Search All Tabs**：すべてのブラウザタブを検索
- **Switch App Tab**：アプリタブを切り替え
- **Run Command**：操作と実行先を選ぶ

Raycastの設定からHotkeyやAliasを追加できます。[連携の詳細](raycast/README.md)

## 詳しい仕様

<details>
<summary>タブ・ログイン環境・保存について</summary>

- アプリタブの中にブラウザタブを持ちます。ログイン環境が異なるとCookieとサイトデータを分離し、同じ環境を選ぶと共有します。
- タブグループの切り替えはタブ列の左端のグループ選択欄、またはタブ列上の上下スクロールで行います。表示するページはタブをクリックするまで切り替わりません。
- アイコンのみのピン留め、別ウインドウへの一時切り離し、作業セットの保存にも対応します。
- 通常のタブ切り替えではページを再読み込みしません。再読み込み中はシマーと案内を表示し、画面のスクリーンショットは撮影・保存しません。表示済みタブの自動破棄は行いません。
- 再起動時は保存したタブのURLを復元します。未送信の入力やページ内部の一時状態は復元対象外です。
- 設定は `~/Library/Application Support/WorkspaceTabs/`、サイトデータはWebKitの永続プロファイルに保存します。現在状態は変更時に自動保存し、復元用の構成履歴は通常5分間隔・読み込みや復元前に残します。直近20件から復旧できます。
- 外部ブラウザのログイン状態を引き継ぐ機能や、ブラウザ拡張のインストールには対応していません。
- グローバルな修飾キーの連続入力には、macOSのアクセシビリティ許可が必要です。
- Liquid GlassはmacOS 26以降で使用します。サイトや認証の対応状況はmacOSのWebKitにも依存します。

[保存・復元・パフォーマンスの詳細](docs/FEATURES.md)

</details>

<details>
<summary>サービス固有の機能・任意の同期</summary>

Notion向けには、ホームURL、ワークスペースIDによる振り分け、サイドバーの着色、作成メニューを用意しています。**⌘⇧N** でカーソル付近にメニューを開き、新規ページ・AIチャット・ミーティングノート・データベース・カスタムページを選び、新しいタブで開けます（Notion側の機能・権限によります）。

**設定 → リンクの受け取り** をオンにすると、Workspace TabsをこのMacの既定ブラウザに変更します。対応するNotionのWebリンクはこのアプリで開き、それ以外は変更前のブラウザへ渡します。オフにすると元へ戻します。初期状態ではOS設定を変更しません。専用アプリを直接指定するリンクなどは対象外になる場合があります。

お気に入りの保存先はローカルが標準です。任意でNotionのデータベースと約1時間ごとに同期でき、タブ構成のバックアップにも使えます。接続情報はKeychainに保存します。

[サービス連携・同期・ワークスペース判定の詳細](docs/FEATURES.md#notion保存と振り分け)

</details>

## ソースからビルド

開発者向けの手順です。macOS 26以降のSDKとSwift 6ツールチェーン（Xcode 26以降、または同等のCommand Line Tools）、Python 3が必要です。初回ビルド前に開発ツールのセットアップを完了してください。

```sh
git clone https://github.com/satoshi0817/workspace-tab.git
cd workspace-tab
bash scripts/build.sh
```

`build/Workspace Tabs.app` が生成されます。Finderで `build` フォルダを開き、アプリを「アプリケーション」へドラッグして起動してください。

配布用DMGもmacOS標準コマンドだけで作成できます。

```sh
bash scripts/package.sh
```

`build/release/` に、ビルドしたCPUアーキテクチャを名前に含むDMGとSHA-256チェックサムを生成します。パッケージ作成だけではAppleの公証は行いません。

## 開発・検証

ビルド済みの状態で、リポジトリのルートから実行します。

```sh
swift run --scratch-path /tmp/workspace-tabs-build WorkspaceCoreChecks
python3 scripts/browser_checks.py
```

ブラウザ検証はローカルのテストページと一時ログイン環境を使います。Raycast拡張は `raycast/` 内で `npm run typecheck` と `npm run build` を実行できます。

初回起動を検証する場合は、次のコマンドで設定とCookieのない環境を毎回作り、Notionの表示を5回確認できます。既存のタブやログイン情報は使いません。インターネット接続が必要で、失敗時はHTTPステータスなどを表示して終了コード1を返します。

```sh
"build/Workspace Tabs.app/Contents/MacOS/WorkspaceTabs" --startup-checks
```

504などが出た場合は[初回起動の検証・切り分け](docs/FIRST_LAUNCH_CHECKS.md)を参照してください。

ビルド時にApple Development証明書があれば署名に使用し、なければアドホック署名します。署名の指定は `WORKSPACE_TABS_SIGN_IDENTITY`、ビルド先の指定は `WORKSPACE_TABS_BUILD_DIR` で行えます。配布用の公証は別途必要です。

| パス | 内容 |
| --- | --- |
| `Sources/WorkspaceTabs/` | macOSアプリ・WebKit・外部連携 |
| `Sources/WorkspaceCore/` | モデル・ルーティングなどの共通処理 |
| `Tests/WorkspaceCoreTests/` | 共通処理の検証 |
| `raycast/` | Raycast拡張 |
| `scripts/` | ビルド・検証スクリプト |
| `docs/` | 詳細仕様・調査記録 |

[パフォーマンスの調査記録](docs/PERFORMANCE_AUDIT.md)。旧ウインドウ管理方式の資料は履歴として `docs/` に残しています。
